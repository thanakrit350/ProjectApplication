# 📍📱 แอปพลิเคชันแนะนำการนัดหมายสถานที่รับประทานอาหาร

**แอปพลิเคชันแนะนำการนัดหมายสถานที่รับประทานอาหาร**  
คือแอปพลิเคชันมือถือที่พัฒนาด้วย **Flutter** เพื่อเป็นแพลตฟอร์มให้กลุ่มเพื่อนหรือสมาชิกในสังคม  
นัดหมายและพบปะรับประทานอาหารร่วมกันได้อย่างสะดวก  
แอปออกแบบโดยคำนึงถึง **ความเรียบง่าย ใช้งานง่าย และลดช่องว่างทางเทคโนโลยี** เพื่อให้ทุกคนเข้าถึงได้

---

## 🎯 เป้าหมายของโปรเจกต์
โปรเจกต์นี้มุ่งเน้นการสร้างแพลตฟอร์มที่ช่วยให้ผู้ใช้สามารถ:

- **ติดต่อสื่อสาร** : แจ้งเชิญเพื่อนเข้าร่วมกิจกรรม นัดหมายวันเวลา และสื่อสารผ่านรายละเอียดกิจกรรม  
- **มีส่วนร่วมกับสังคม** : สร้างและเข้าร่วมกิจกรรมการรับประทานอาหารร่วมกับผู้อื่น เพื่อสร้างความสัมพันธ์ในกลุ่มเพื่อนหรือครอบครัว  
- **เข้าถึงข้อมูลสำคัญ** : ดูรายละเอียดร้านอาหาร เวลาเปิด–ปิด พิกัด และข้อมูลกิจกรรมต่าง ๆ ได้ในที่เดียว  

---

## 🌟 คุณสมบัติหลัก
- **Add Post Activity** : ผู้ใช้สามารถสร้างกิจกรรม นัดหมายวันและเวลา ระบุร้านอาหารหรือให้เพื่อนช่วยโหวตร้าน  
- **Join Activity** : ผู้ใช้สามารถเข้าร่วมกิจกรรมที่สร้างไว้ ดูรายชื่อผู้เข้าร่วม และติดตามสถานะการนัดหมาย  
- **Select Choice** : สมาชิกในกิจกรรมสามารถโหวตร้านอาหารเพื่อช่วยตัดสินใจเลือกสถานที่รับประทานอาหารร่วมกัน  
- **View Restaurant** : ดูรายละเอียดร้านอาหาร เช่น รูปภาพ เวลาเปิด–ปิด ตำแหน่งร้านอาหาร และเส้นทางไปยังสถานที่นัดหมายแบบเรียลไทม์  

---

## 🛠️ เทคโนโลยีที่ใช้
โปรเจกต์นี้พัฒนาด้วย **Flutter** สำหรับส่วนหน้าบ้าน (Frontend) และใช้เทคโนโลยีที่แข็งแกร่งสำหรับส่วนหลังบ้าน (Backend) ดังนี้ครับ

- **Flutter** : พัฒนาแอปพลิเคชันให้ทำงานได้ทั้ง **iOS** และ **Android** จากโค้ดเบสเดียว พร้อม UI ที่ตอบสนองรวดเร็ว  
- **Spring Boot API** : เป็นเทคโนโลยีหลักสำหรับส่วนหลังบ้าน ทำหน้าที่จัดการข้อมูลทางธุรกิจและให้บริการ **RESTful API** สำหรับแอปพลิเคชัน  
- **MySQL** : เป็นระบบจัดการฐานข้อมูล (**Database**) ที่ใช้ในการจัดเก็บข้อมูลสำคัญทั้งหมดของแอปพลิเคชัน  
- **OpenStreetMap & Leaflet** : ให้บริการแผนที่ ค้นหาร้านอาหาร และคำนวณเส้นทางเดินทางแบบเรียลไทม์
